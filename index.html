Escolhas do Leitor

Que nossos leitores adoram

  • HTML and CSS: Design and Build Websites

    Este livro é ideal para iniciantes, com uma abordagem visual e didática que facilita o entendimento da estrutura da web. Ele ensina com clareza os fundamentos de HTML e CSS, essenciais para qualquer desenvolvedor, tornando a entrada no universo do front-end muito mais acessível e menos intimidadora.

    Jon Duckett

  • Eloquent JavaScript, 4th Edition

    Um dos melhores livros para aprender JavaScript de forma progressiva e prática. Ele começa com conceitos básicos e evolui para tópicos avançados como funções de ordem superior, closures e programação funcional, além de incluir exercícios práticos que solidificam o aprendizado.

    Marijn Haverbeke

  • Don't Make Me Think

    Apesar de não ser técnico, é fundamental para desenvolver o olhar de um bom web developer. O livro trata da usabilidade de forma simples, ensinando como pensar como um usuário e projetar interfaces intuitivas.

    Steve Krug

  • You Don’t Know JS

    Esta série é voltada para quem quer realmente dominar JavaScript e entender o que acontece “por trás das cortinas” da linguagem.

    Kyle Simpson
